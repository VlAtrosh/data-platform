## Письмо 1. Ревью конвейеров

### 1. Выручка доставленных заказов от ноутбуков.

- Решение: есть ошибка — сумма по полю заказа после $unwind — итог повторён в каждой позиции — верно
- Комментарий: после $unwind: "$items" документ размножается по каждому товару в заказе. Затем $sum: "$total" складывает полную сумму заказа столько раз, сколько в заказе позиций
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $match: { "items.category": "ноутбуки" } },
  { $group: { _id: null, revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } }
]
```

### 2. Сколько заказов в пути в каждом городе.

- Решение: есть ошибка — $project перед стадией, которой нужно отброшенное поле — верно
- Комментарий: $match стоит после $project, а в $project оставлены только number и delivery - поле status отброшено
- Исправленный конвейер:

```js
[
  { $match: { status: "в пути" } },
  { $group: { _id: "$delivery.city", orders: { $sum: 1 } } },
  { $sort: { _id: 1 } }
]
```

### 3. Номер первого по дате заказа каждого покупателя из трёх: c-007, c-011, c-018.

- Решение: есть ошибка — $first или $last без $sort перед $group — верно
- Комментарий: $first берёт первое попавшееся значение в порядке, в котором документы пришли в $group, а порядок не гарантирован
- Исправленный конвейер:

```js
[
  { $match: { customer_id: { $in: ["c-007", "c-011", "c-018"] } } },
  { $sort: { created_at: 1 } }, 
  { $group: { _id: "$customer_id", first: { $first: "$number" } } },
  { $sort: { _id: 1 } }
]
```

### 4. Пять самых дорогих доставленных заказов.

- Решение: есть ошибка — стадии стоят не в том порядке: $limit срабатывает раньше отбора — верно
- Комментарий: $match по статусу стоит после $sort и $limit. Сначала берутся 5 самых дорогих заказов вообще (включая недоставленные), и только потом среди них фильтруются доставленные - поэтому в ответе лишь два заказа
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $sort: { total: -1 } },
  { $limit: 5 },
  { $project: { _id: 0, number: 1, total: 1 } }
]
```

### 5. Выручка доставленных заказов по способам оплаты.

- Решение: есть ошибка — путь к полю записан без знака $ — верно
- Комментарий: _id: "payment.method" - это строковый литерал, а не путь к полю. Нужен $ перед путём: _id: "$payment.method"
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $group: { _id: "$payment.method", revenue: { $sum: "$total" } } }
]
```

### 6. Сколько штук смартфонов продано в доставленных заказах.

- Решение: есть ошибка — условие на результат группы стоит до $group — неверно
- Комментарий: $match: { "items.category": "смартфоны" } до $unwind оставляет только заказы, где есть хотя бы один смартфон, но после $unwind в группировку попадают все позиции такого заказа - включая ноутбуки, аксессуары и т.д
- Исправленный конвейер:

```js
[
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $match: { "items.category": "смартфоны" } },
  { $group: { _id: null, qty: { $sum: "$items.qty" } } }
]
```

### 7. Средний чек доставленных заказов в каждом городе, округлённый до рубля, по убыванию.

- Решение: конвейер верный — верно
- Комментарий: $match корректно отбирает доставленные заказы; $group по $delivery.city считает среднее $avg по total; $round с точностью 0 округляет до рубля

### 8. Три самых продаваемых по штукам товара в доставленных заказах.

- Решение: конвейер верный — верно
- Комментарий: $match берёт только доставленные; $unwind разворачивает позиции; $group по $items.title суммирует qty — получаем продажи по каждому товару;

## Письмо 4. Свои конвейеры

### 1. Доставленные заказы по способу доставки: _id — способ (delivery.type), orders — число заказов, revenue — выручка. По убыванию revenue.

```js
db.orders.aggregate(db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $group: { 
      _id: "$delivery.type", 
      orders: { $sum: 1 }, 
      revenue: { $sum: "$total" } 
  } },
  { $sort: { revenue: -1 } }
]))
```

- Результат совпадает с нужным, запусков: 1

### 2. Коллекция products. Средняя цена товаров каждой категории, округлённая до рубля: _id — категория, avg — средняя цена. По возрастанию avg.

```js
db.products.aggregate(db.products.aggregate([
  { $group: { 
      _id: "$category", 
      avg: { $avg: "$price" } 
  } },
  { $project: { 
      avg: { $round: ["$avg", 0] } 
  } },
  { $sort: { avg: 1 } }
]))
```

- Результат совпадает с нужным, запусков: 1

### 3. Покупатели, у которых сумма доставленных заказов больше 400 000: _id — customer_id, spent — сумма. По убыванию spent.

```js
db.orders.aggregate(db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $group: { 
      _id: "$customer_id", 
      spent: { $sum: "$total" } 
  } },
  { $match: { spent: { $gt: 400000 } } },
  { $sort: { spent: -1 } }
]))
```

- Результат совпадает с нужным, запусков: 1

### 4. Для каждого города — массив номеров отменённых заказов по возрастанию номера: _id — город, numbers — массив. Города по алфавиту.

```js
db.orders.aggregate(db.orders.aggregate([
  { $match: { status: "отменён" } },
  { $group: { 
      _id: "$delivery.city", 
      numbers: { $push: "$number" } 
  } },
  { $project: { 
      numbers: { $sortArray: { input: "$numbers", sortBy: 1 } } 
  } },
  { $sort: { _id: 1 } }
]))
```

- Результат совпадает с нужным, запусков: 1

### 5. Одним запросом по доставленным заказам: в поле total — массив из одного документа { orders: число заказов }, в поле top — три товара с наибольшим числом штук (_id — название, qty — штуки), по убыванию qty, при равенстве — по названию.

```js
db.orders.aggregate(db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $facet: {
      total: [
        { $count: "orders" }
      ],
      top: [
        { $unwind: "$items" },
        { $group: { 
            _id: "$items.title", 
            qty: { $sum: "$items.qty" } 
        } },
        { $sort: { qty: -1, _id: 1 } },
        { $limit: 3 }
      ]
  } }
]))
```

- Результат совпадает с нужным, запусков: 1
