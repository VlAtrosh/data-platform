# Домашнее задание № 1 · своя коллекция и шесть запросов

Срок — до начала занятия 2. Работа идёт в стенде с пары, Compass подключён
к `mongodb://localhost:27017`.

## Задание

1. Собрать свою коллекцию из пяти документов, сохранить их в `seed.json`.
2. Выполнить к ней шесть запросов, записать фильтры и числа в `queries.md`.
3. В конце `queries.md` написать несколько предложений о повторах
   в документах.

## Коллекция

Любая понятная область: заказы, тикеты, объявления, запись на приём.
В документах должны встретиться вложенный объект, массив, число и строка,
а у двух документов форма должна отличаться. Файл `seed.json` должен
загружаться через **ADD DATA → Import JSON or CSV file** без правок руками.

## Запросы

| № | Что ищем | Пример |
|---|---|---|
| 1 | точное совпадение строки | `{ city: "Ярославль" }` |
| 2 | поле внутри объекта | `{ "education.level": "СПО" }` |
| 3 | элемент массива | `{ skills: "MongoDB" }` |
| 4 | сравнение чисел | `{ salary: { $gt: 100000 } }` |
| 5 | наличие поля | `{ portfolio: { $exists: true } }` |

Шестой запрос — заведомо неправильный. Напишите, что именно произошло:
ошибка разбора (кнопка Find не нажимается) или пустой результат
(`0 – 0 of 0`).

## Повторы

Какое значение повторяется в нескольких документах, что придётся менять, если
документов станет двести, и почему вы всё-таки оставили повтор.
