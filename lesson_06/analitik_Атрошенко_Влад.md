## Письмо 1. Ревью запросов

### Запрос 1. Заказчику нужны резюме с ожиданиями по зарплате от 100 000 ₽ и выше.

```js
db.resumes.find({ salary: { $gte: "100000" } })
```

- Решение: есть ошибка — значение не того типа: строка вместо числа или логического значения — верно
- Комментарий: Ошибка в типе данных для сравнения.  Salary храниться как число
- Исправленный запрос:

```js
db.resumes.find({ salary: { $gte: 100000 } })
```

### Запрос 2. Найти кандидатов с высшим образованием.

```js
db.resumes.find({ education: { level: "Высшее" } })
```

- Решение: есть ошибка — вложенный документ сравнивается целиком — нужна точечная нотация — верно
- Комментарий: В запросе MongoDB воспринимает значение { level: "Высшее" } как документ целиком и ищет полное совпадение по полю education
- Исправленный запрос:

```js
db.resumes.find({ "education.level": "Высшее" })
```

### Запрос 3. Кандидаты, которые знают и SQL, и Python.

```js
db.resumes.find({ skills: { $in: ["SQL", "Python"] } })
```

- Решение: есть ошибка — условия нужно объединить через $or, а они записаны через «и» — неверно
- Комментарий: А заказчику нужны кандидаты, которые знают и SQL, и Python одновременно. Условие $in это требование не выполняет
- Исправленный запрос:

```js
db.resumes.find({ skills: { $all: ["SQL", "Python"] } })
```

### Запрос 4. Кандидаты, которые проработали в Retail Lab не меньше 12 месяцев.

```js
db.resumes.find({ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } })
```

- Решение: есть ошибка — условия на массив документов выполняются в разных элементах — нужен $elemmatch — верно
- Комментарий: Поле experience - это массив вложенных документов, но у кандидата может быть несколько мест работы
- Исправленный запрос:

```js
{ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } }
```

### Запрос 5. Открытые вакансии в Москве, где верхняя граница зарплаты не меньше 160 000 ₽.

```js
db.vacancies.find({ city: "Москва", is_open: true, "salary.to": { $gte: 160000 } })
```

- Решение: запрос верный — верно
- Комментарий: Все верно, запрос правильный

### Запрос 6. Все резюме на должности, в названии которых есть слово Python.

```js
db.resumes.find({ position: /python/ })
```

- Решение: есть ошибка — регистр букв: шаблон без флага i — верно
- Комментарий: MongoDB чувствительный к регистру
- Исправленный запрос:

```js
db.resumes.find({ position: /python/i })
```

### Запрос 7. Резюме с ожиданиями от 70 000 до 100 000 ₽ включительно.

```js
db.resumes.find({ salary: { $gte: 70000 }, salary: { $lte: 100000 } })
```

- Решение: есть ошибка — ключ в фильтре повторяется — первое условие пропадает — верно
- Комментарий: два одинаковых ключа
- Исправленный запрос:

```js
db.resumes.find({ salary: { $gte: 70000, $lte: 100000 } })
```

### Запрос 8. Финальные собеседования в московских компаниях, которые проходили по видеозвонку.

```js
db.interviews.find({ "company.city": "Москва", format: "видеозвонок", stage: "финальное" })
```

- Решение: запрос верный — верно
- Комментарий: Все три условия объединены через запятую, что означает логическое «И»
